# 01 为什么需要区块链

> **导航**：[← 目录](../README.md) · [目录](../README.md) · [下一章：02 密码学前置知识 →](02-cryptography-basics.md)

> 在讨论任何技术细节之前，先回答一个根本问题：**区块链到底解决了什么问题？**

## 1. 信任从哪来

人类的一切协作都建立在「信任」之上。问题是：信任如何被保证？

在传统世界里，我们通常把信任**委托给一个中心机构**：

- 银行替我们记账，我们相信它不会赖账；
- 政府替我们登记产权，我们相信它不会篡改；
- 平台替我们托管数据，我们相信它不会滥用。

这种「中心化信任」运转了几百年，它高效、成熟，但有三个绕不开的软肋：

1. **单点失败**：中心机构一旦出问题（破产、被攻击、决策失误），整个体系跟着遭殃。
2. **作恶空间**：掌握账本的人可以偷偷篡改记录——删掉一笔、多记一笔，普通用户很难察觉。
3. **信任成本**：为了维持信任，我们需要审计、监管、诉讼，这些都要付出真金白银和时间。

区块链的出发点，就是回答一个看起来很狂的问题：**能不能在没有中心机构的情况下，让互不信任的人就「同一本账」达成一致？**

## 2. 电子现金的历史难题：双花

在互联网出现之前，钱的流转依赖物理实体：纸币交到你手上，我就不再拥有它，「一份钱花两次」在物理上不可能。

但电子数据不一样。一段信息可以被无限复制——如果我给你发一个文件，我自己还留着一份。于是「电子现金」从诞生起就面临一个经典难题：**双花（Double Spending）**。我如何保证同一条数字记录不会被花两次？

中心化方案很简单：让银行做唯一记账人，每次交易都问银行「这钱还在吗」。去中心化方案则必须回答：**没有唯一的记账人，谁来保证没人重复花钱？**

比特币之前的多次尝试（如 1990 年代的 DigiCash、后来的 e-gold 等）都倒在这个问题上——它们最终都需要一个中心实体来防双花，也就回到了中心化信任的老路。

## 3. 分布式账本：每个人都有一本账

区块链的核心思想极其朴素：**与其让一个人记账，不如让所有参与者一起记账。**

想象一个记账网络：

- 网络里有成千上万个节点，每个节点都保存**同一份完整的账本副本**；
- 新交易产生后，广播给全网；
- 大家按照**共同规则**把交易打包进「区块」，再用密码学手段把区块**前后串联**成一条链；
- 谁想篡改历史，就必须同时改掉网络中大多数副本——这几乎不可能。

由此得到三个让区块链成立的性质：

| 性质 | 含义 | 靠什么保证 |
| --- | --- | --- |
| **不可篡改** | 已确认的历史记录几乎无法更改 | 哈希链 + 算力/权益门槛 |
| **公开可验证** | 任何人都能核对账本，无需信任某个机构 | 数据公开 + 密码学验证 |
| **去中心化** | 没有一个节点说了算 | 共识机制 + 网络冗余 |

注意一个容易误解的点：区块链不是「没有信任」，而是把「信任某个机构」**替换为「信任数学和规则」**。你不必相信张三李四，只需要相信：没人能同时控制网络中足够多的节点。

## 4. 区块链 vs 普通数据库

有人问：这不就是个共享数据库吗？差别确实微妙，但关键在**信任模型**：

| 维度 | 传统数据库 | 区块链 |
| --- | --- | --- |
| 谁有写权限 | 中心管理员 | 全网按共识规则 |
| 谁能读 | 由管理员决定 | 公开链上任何人 |
| 历史能否改动 | 可以 UPDATE / DELETE | 原则上不可 |
| 失败风险 | 中心故障即服务中断 | 部分节点掉线不影响 |
| 成本 | 低 | 高（冗余存储 + 共识开销） |

**区块链并不「优于」数据库**——它更慢、更贵、更难维护。它只在一种场景下有意义：**参与方互不信任、且无法接受单一权威时**。这也是为什么区块链天然适合数字货币、资产确权、多方协作这类场景，而不是用来存一张「员工通讯录」。

## 5. 从比特币到 Web3：概念的扩展

2009 年，比特币把「去中心化账本」变成了现实，但它只做一件事：**记账（转账）**。

随后人们意识到：如果账本不只是记录「谁有多少钱」，而是能记录「任何状态的变迁」，那它就是一台**全世界共享的计算机**。以太坊把「可编程状态」引入链上，智能合约随之出现；再往后，身份、存储、域名、组织形态（DAO）陆续上链，「Web3」这个词逐渐成型。

一句话概括演进路径：

> **分布式账本（比特币）→ 可编程账本（以太坊/智能合约）→ 开放应用生态（Web3）**

## 本章小结

- 区块链解决的是**无中心信任下的记账一致性问题**；
- 它的价值来自**不可篡改 + 公开可验证 + 去中心化**三件套；
- 它是**信任模型的替换**，不是数据库的升级版；
- 理解「为什么需要它」，比记住任何术语都重要。
