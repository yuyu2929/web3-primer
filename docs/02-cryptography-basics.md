# 02 密码学前置知识

> 区块链不是密码学，但它**建在密码学之上**。本章只讲两块地基：哈希函数与数字签名。

## 1. 哈希函数：内容的「指纹」

哈希函数把任意长度的输入，映射成固定长度的输出（如 256 位）。区块链用的是**密码学哈希**（如 SHA-256），它有三个关键性质：

1. **确定性**：同一输入，永远得到同一输出。
2. **单向性**：从输出反推输入，在计算上不可行。
3. **抗碰撞**：几乎找不到两个不同输入得到同一输出。

可以把哈希理解为内容的**指纹**：只要内容动一个比特，指纹就面目全非。

```text
输入: "hello"     → SHA-256: 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
输入: "hellp"     → SHA-256: fdd7585e08c4e2afd71dcabdb4636c89d557a3f42db9e2040c8bbd1708aa4ce7
```

### 哈希在链上的三个用途

- **内容寻址**：用哈希作为数据的地址，谁给出一段数据，谁就能验证它确实是原样。
- **篡改检测**：把大量数据压缩成一个哈希，就能快速发现任何改动。
- **Merkle 树**：把一组交易两两哈希、逐层合并，最终得到一个根哈希。只要保留根哈希，就能高效证明「某条交易确实在这组交易里」，而不必下载全部数据。这是比特币区块结构的基础。

## 2. 非对称加密：一把钥匙分两半

传统密码学是「对称」的：加密和解密用同一把钥匙，问题是怎么安全地把钥匙交给对方。

非对称加密换了个思路：**生成一对数学上关联的钥匙——公钥与私钥**。

- **私钥**：自己保管，绝不示人；
- **公钥**：公开分发，人人可得；
- 由公钥推不出私钥（计算上不可行）。

这把「钥匙对」支持两种相反的操作，恰好对应两种需求：

| 需求 | 操作 | 说明 |
| --- | --- | --- |
| **加密** | 公钥加密，私钥解密 | 任何人都能给你发密文，只有你能读 |
| **签名** | 私钥签名，公钥验签 | 只有你能签署，任何人都能验证是你签的 |

区块链主要用到**签名**。

## 3. 数字签名：链上所有权的本质

在区块链里，「你有多少币」不是靠账户系统记录，而是靠一条条 **UTXO / 余额记录 + 签名授权** 实现的。核心逻辑是：

1. 你拥有一个地址，本质是**你拥有这把地址对应私钥**；
2. 要花一笔钱，你必须用**私钥**对这笔交易签名；
3. 全网用你的**公钥**验证签名：签名有效 → 确实是你授权的 → 交易有效。

由此得出整条链最重要的心智模型：

> **在区块链上，「拥有」= 持有私钥；「花出去」= 用私钥签名。**
>
> 谁掌握了私钥，谁就掌握了资产。**私钥就是一切，丢了私钥 = 丢了资产**，没有任何客服可以帮你找回。

### 地址是怎么来的（以典型流程为例）

```text
私钥 ──椭圆曲线算法──> 公钥 ──哈希──> 地址
（随机数）      （公开）         （对外展示）
```

地址可以理解为公钥的「缩写名片」：公开、短小、便于转账。验证签名时，节点用公钥验签；而外界只需要知道地址，不需要知道你的公钥原文——这就是地址设计的意义。

## 4. 助记词：让私钥可被人类记忆

私钥是一长串随机数，没人能背下来。于是有了 BIP-39 助记词标准：

- 从 2048 个单词的词典里，按规则挑 12/15/18/21/24 个单词（熵分别为 128/160/192/224/256 位）；
- 这组单词**可以确定性地推导出私钥**；
- 所以：**助记词 = 私钥的人性化备份**。抄写助记词的纸，价值等同于你的全部链上资产。

现代钱包几乎都用助记词 + 派生路径（BIP-32/44）管理多把私钥：一组助记词，派生出整个钱包的所有账户。

## 5. 两个常被误解的点

1. **「去中心化」不等于「匿名」**：地址虽不直接关联真实身份，但所有交易公开可查，配合链上分析完全可以追踪。区块链更多是**假名制（Pseudonymous）**，不是匿名制。
2. **「不可篡改」不等于「绝对不可改」**：改单条记录很难，但如果攻击者控制了足够多的算力/质押，理论上可以重写近期历史（见下一章共识机制的 51% 攻击）。不可篡改是**经济上的不可行**，不是逻辑上的不可能。

## 本章小结

- 哈希函数 = 内容指纹，负责**防篡改**与**高效校验**；
- 数字签名 = 私钥授权证明，负责**所有权**与**交易合法性**；
- 地址是公钥的简化形态，**私钥是链上资产的唯一凭证**；
- 助记词是私钥的可记忆备份，务必离线妥善保管。
